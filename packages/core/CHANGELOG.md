# @pipeline-view/core

## 1.0.0

### Major Changes

- First stable release of pipeline-view: interactive process / P&ID diagrams for live SCADA-style monitors and diagram editors. It includes the framework-agnostic core (model, undo/redo, orthogonal routing with line jumps, SVG renderer with HTML overlay, editor, accessibility, export, theming), 50 gas-service P&ID symbols plus process equipment, and React bindings.

### Minor Changes

- 568d8fc: Accessibility and export. Nodes get `role="button"`, an `aria-label` (label or id, symbol name, status) and a roving tabindex. Keyboard: arrows move focus to the nearest node (Alt+arrows in edit mode), Home/End jump to the first/last node, Enter selects and emits nodeClick, Escape clears the selection, +/-/0 zoom. A focus ring is drawn with `--pv-focus-ring`. `exportSVG()` returns a standalone SVG (computed styles inlined, editing chrome removed, HTML overlays as foreignObject), and `exportPNG({ scale })` rasterizes it. Both can export the whole diagram or the visible viewport.
- 07cef09: Add the headless `Diagram` class: model store with `load`/`toJSON` round-trip and validation, transactional `update()` with undo/redo, `preview()`/`commitPreview()`/`cancelPreview()` for interactive gestures, the `setNodeData`/`setNodeDataBatch` live-data fast path (no undo, no modelChange), typed events and selection.
- 2ccaf81: Match the Figma reference more closely and fix view-mode clicks. A selected node now gets a rounded selection box (`--pv-selection-bg`, `--pv-selection`, `--pv-selection-radius`) and a selection-coloured label. Nodes get a transparent hit box, so clicks inside stroke-only symbols select them. Leader lines are routed orthogonally around nodes, or follow the new optional `leaderWaypoints` on annotations. Pointer capture is taken only once a press becomes a pan, so a plain click in the browser reaches the node instead of being retargeted to the root.
- d8aad9f: Draw pneumatic signal links as solid lines with paired `//` tick marks (Figma reference #50; spacing set by `--pv-tick-spacing`, and `--pv-line-pneumatic-dash` now defaults to `none`). Signal-kind arrows and ticks use `--pv-line-signal`. Add the optional background grid (`grid: { size, visible: true }`), drawn in screen space with `--pv-grid`, following pan and zoom and hidden when denser than 6 px.
- 6f0c37f: Add annotations and the HTML overlay. Text annotations render as SVG text (`label` / `area` / `legend` variants). HTML annotations and nodes with `data.overlay` mount through `htmlRenderers`, positioned in diagram space and never rotated. Anchored annotations follow their node and receive its live data. Leader lines connect an annotation to its anchor (FR-18). Pointer events are emitted (`nodeClick`, `nodeDoubleClick`, `linkClick`, `contextMenu`, `hover`), with click-to-select in view mode.
- 39d5baf: Add the SVG renderer and `styles.css`. Nodes come from the SymbolRegistry with rotation/flip, unrotated labels, `data-status` and ports. Links are drawn by kind (process / signal / electrical / pneumatic), with flow arrows, the `data.flowing` animation (respects reduced motion), selection, line jumps and junction dots from the orthogonal router. Updates are dirty-tracked and batched per animation frame; data ticks never reroute. `styles.css` ships every `--pv-*` token with light and dark themes (`data-theme` or `prefers-color-scheme`).
- 4351092: Add `diagram.mount(el)` with the layered SVG + HTML-overlay DOM skeleton, the viewport (pan by drag/middle button/space, wheel and trackpad zoom, two-finger pinch, animated `setViewport` respecting reduced motion, `zoomToFit`, `zoomToItem`, screen↔diagram transforms, `getBounds`), `hitTest()`, and pure node geometry helpers (`nodeBounds`, `portPoint`, `resolvePorts`, `nodeTransform`).
- d69a0fd: Add the DOM-free editor command layer (`EditorCommands`): drag-move with grid snap and alignment guides (one undo step per gesture), rotate/flip, delete, copy/cut/paste/duplicate, port-compatibility checks and connect (`accepts` + `canConnect`), palette drop (`canDrop`), manual waypoint editing helpers, inline label edits, and the editor keymap (`actionForKey`).
- 45d31c3: Add the edit-mode input layer: `EditorController` / `attachEditor(diagram)` wires pointer, keyboard and palette drag-and-drop (`SYMBOL_MIME`) to `EditorCommands`: click / shift-click / marquee selection, node drag with snap and alignment guides, port-to-port connect with compatible-port highlighting, rotate handle and R key, link segment drag and bend add/remove, inline label editing, and all editor shortcuts including undo/redo.
- 4f914ec: Add `OrthogonalRouter` / `createRouter()`: orthogonal, node-avoiding pipe routing (sparse-grid A* with bend penalty and clearance), manual waypoints, parallel-pipe spreading, incremental `updateObstacle`, and `analyze()` for line-jump crossings and branch junctions. Adds `Router.removeRoutes()` to the routing contract.

### Patch Changes

- a9502e2: The renderer now uses the incremental `RouteAnalyzer` (drag frames re-check only rerouted links) and refreshes line jumps and junction dots when links are deleted without a reroute. Editor: `linkKind` option and `setLinkKind()` for new connections (falls back to the start port's accepted kind), `getEditor(diagram)` to reach the attached controller, connect-target circles reused during the drag, and the inline label editor follows pan/zoom.
- b2610fc: Editor: take pointer capture only once a press turns into a drag, so plain clicks in edit mode still reach the clicked item (`nodeClick`, `linkClick`).
- e839f4e: The editor draws its adornments in its own `<g class="pv-editor">` inside the interaction layer, so it no longer clears other content there (such as the keyboard focus ring).
- 98e5f51: Fix: the renderer and overlay no longer call `clearTimeout()` with `requestAnimationFrame` ids. Because rAF ids and timer ids are separate counters, that could silently cancel an unrelated host `setTimeout` or `setInterval` with the same number (for example a live-data polling interval).
- 3636bfe: Add `RouteAnalyzer`, an incremental line-jump/junction analysis: `update(changedRoutes)` re-checks only the changed links against a spatial index, so drag frames no longer pay for a whole-diagram `analyze()`. `Router.analyze()` now uses it internally (same results).
- 8256595: Leaders with `leaderWaypoints` now end at the final waypoint when it lies on or inside the anchor node's bounds, instead of adding an extra leg to an edge (matches Figma leaders that meet a vessel shell).
- 3242c88: Package metadata for 1.0: keywords, homepage, bugs, engines, `publishConfig.access`, a README and LICENSE in each package. CI now packs every package and verifies the tarball contents and type resolution.
- 6d223c2: Faster pan/zoom: the viewport no longer writes a `--pv-zoom` custom property on the root every frame. Nothing read it, and each write forced a style recalculation across the whole diagram subtree (about 52 → 60 fps at 500 nodes / 1,000 links).
- 5786165: SSR safety is now tested: every package is imported and exercised in plain Node with no DOM, and `<PipelineView>` server-renders with its hooks.
- 047c29d: Add `<SymbolPalette/>`: searchable (name, keywords, category, type, ref number), grouped by category in P&ID order, symbol previews, HTML5 drag to a `<PipelineView>` in edit mode, and click/Enter to insert at the center of the view. Core `styles.css` gains the palette and editor-adornment styles (tokens only).
