# pipeline-view

TypeScript library for interactive P&ID and process diagrams, built for the gas industry and open to any process industry.

- 50+ P&ID symbols (valves, actuators, compressors, vessels, instruments, piping) plus a custom-symbol API
- Orthogonal, node-avoiding pipe routing with manual waypoints and line jumps
- Live values via arbitrary HTML / React overlays — no transport lock-in
- Viewer and editor modes in one component
- Light and dark themes via CSS tokens
- Framework-agnostic core, React bindings first

> **Status:** pre-implementation. See [PRD.md](./PRD.md) for scope, requirements and milestones.
